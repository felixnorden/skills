# Specification

This repository no longer keeps a copy of the Agent Skills format
specification. A copy drifts from the source.

Authoritative source: https://agentskills.io/specification

The local copy was removed on 2026-10-05.

`AGENTS.md` is the normative authoring standard for this repository. It applies
the upstream specification and the current best-practices guidance. Where
`AGENTS.md` is stricter than the upstream specification, `AGENTS.md` wins for
skills in this repository.

Run `bun run scripts/validate-skills.ts` to check a skill against the mechanical
rules.
