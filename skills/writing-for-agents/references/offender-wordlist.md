# Offender wordlist

Word tables for the patterns in SKILL.md. Replace the left column with the right column. When the fix column says "cut", delete the word. The sentence must then work without it or get a real measure.

## Superlatives and intensifiers

| Word | Fix |
|---|---|
| extremely, very, highly, incredibly, absolutely | cut, or state the measure |
| significantly, dramatically, considerably | the measure |
| crucial, vital, essential, critical | "needed for X", or cut |
| key, core, major | cut, or name what it does |
| massive, huge, enormous | the size or count |
| unprecedented | the fact |
| groundbreaking, revolutionary, cutting-edge | the fact |
| world-class, state-of-the-art | the fact |
| powerful, comprehensive, robust, scalable | the fact the word stands in for |
| seamless, effortless | the steps |
